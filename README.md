- 🤖 Building with **Codex, AgentScope Java, and MCP**, with a focus on useful Agent workflows
- 🧰 Turning real-world needs into self-hosted development tools, browser assistants, and automation scripts

- **Agent applications in Java** — Build streaming chat experiences with AgentScope, session memory, tool calls, and Ollama or compatible model APIs

- **Everyday browser tools** — Bring AI summaries and in-page translation to the browser, alongside media downloads and productivity helpers
